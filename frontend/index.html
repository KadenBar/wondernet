✳ MEET WONDERNET

A little internet.
No internet needed.

Imagine a whole world of learning, books and games on a tiny local Wi-Fi network. No open web, no subscriptions, just room to get curious.

That's the WonderNet goal. We're building a safer offline internet for kids, and sharing the code so anyone can help make it better.

⌁ WIFI ≠ INTERNET

THE WHOLE REASON WE'RE HERE

Three things we're not compromising on.

⌁

01 / THE IDEA

Offline, on purpose.

Kids will connect to a Raspberry Pi over local Wi-Fi. The plan is a contained experience, not a doorway to the public internet.

Pi networking is on the roadmap
Aa

02 / THE GOOD STUFF

Learning should be fun.

Reading, math, science, coding and useful life skills, right alongside games, stories and a place to experiment.

Two tiny learning demos are playable
✳

03 / FOR EVERYONE

Free code. Open doors.

No software subscriptions or paywalls. Anyone can inspect the code, contribute ideas and eventually build their own on compatible hardware.

Source code is public now
