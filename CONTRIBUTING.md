# Contributing to WonderNet

Thanks for helping build a safe, accessible offline learning and play environment.

- Discuss substantial features before contributing.
- Add backend tests and manual accessibility test notes for UI changes.
- Never include children's data, credentials, analytics trackers, ads, or external runtime dependencies.
- No arbitrary server-side student code execution, unsafe upload execution, or unreviewed dependencies.
- Document learning objectives, learner levels, accessible alternatives, and asset licenses.
- Run `python -m pytest -q` before opening a pull request.
- Report vulnerabilities privately rather than in public issues.

Be respectful and welcoming to people of all ages, abilities, and experience levels.
