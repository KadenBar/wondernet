# Accessibility Baseline

Target WCAG 2.2 AA where applicable. A passing automated audit is not proof of compliance.

- Semantic markup, skip links, responsive text, high contrast, keyboard focus.
- Navigation usable without a mouse; sufficient touch target sizes.
- No essential interaction that depends only on color, sound, or drag and drop.
- Respect reduced motion and avoid auto-playing media and unnecessary countdowns.
- Include captions, transcripts, and offline narration with non-audio alternatives.
- Make early literacy accessible without infantilizing older learners using foundational materials.
- Games require adjustable controls, speed, difficulty, pause and alternatives.
- User preferences should work platform-wide; test with assistive technology and disabled learners.

The prototype is not yet comprehensively accessibility tested.
